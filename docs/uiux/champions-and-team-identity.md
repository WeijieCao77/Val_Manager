# 上海冠军赛应援与完整战队背景

2026-09-24，Beta 功能发布说明。更新公告与应援页面均提示测试版本可能存在问题。

## 展示规则

五个不同选手和一名教练必须全部有同一 clubId，才启用完整战队背景。缺人、缺教练、混队均不启用。阵容、分享画布和比赛结算共用队色与 SVG 背景，使用现有本地队标；不改变战力或比赛计算。杯赛结算使用报名阵容快照。

本地视觉样例：`http://127.0.0.1:5174/preview/team-identity.html`（开发服务）。包含阵容、实际生成的分享画布和模拟比赛结算；不读取或写入账号。

## 赛事与留言

独立入口 `/champions`，首页和开瓦包导航均可进入。首页/开瓦包每个比赛日首次进入弹出北京时间赛程，同一浏览器每天一次；休赛日不弹窗。首次开赛日显示“今日开战”，后续日期使用比赛日文案。

赛事范围 2026-09-24 至 2026-10-18：
- 官方公告：https://valorantesports.com/en-US/news/champions-shanghai-everything-you-need-to-know
- 赛程：https://www.vlr.gg/event/matches/2766/valorant-champions-2026
- 日历：https://www.vlr.gg/event/ical/2766
- 首日北京时间 17:00 Team Liquid vs Paper Rex；20:00 TYLOO vs G2 Esports。

请求触发服务端每 30 分钟同步一次，前端每分钟读取。同步失败继续使用数据库缓存或随版本附带的赛程，并标注同步延迟。尚未确定的队伍显示“对阵待定”；以官方最新通知为准。后台可覆盖单日赛程、设置无比赛，或恢复自动同步。没有额外定时任务。

登录用户投稿：支持对象最多 40 字，正文 2–200 字；每分钟一条、滚动 24 小时最多五条。所有新留言为待审核，公开接口仅返回已通过的留言。重复请求不会重复入库。后台支持通过、不通过、撤下、审核说明和审核记录，使用现有管理员认证。公开响应不包含账号 ID 或其哈希。禁用投稿与每日弹窗是独立开关。

## 验证

- 专项自动测试：六人条件、时区、休赛日、日历失效回退、认证、输入校验、隐私、幂等、限频、审核冲突、公开/撤下、赛程覆盖/恢复。
- 本地隔离数据库浏览器实测：建号、留言、待审不公开、后台通过后公开、撤下后隐藏、首日自动弹窗。
- 浏览器检查：390px 手机页面与弹窗；完整战队阵容、分享画布和结算实际渲染。
- 构建、首页依赖隔离、旧浏览器 API 检查和数据库就绪检查通过。

本地审核测试使用独立内存数据库，不连接正式账号；重启后测试留言会清空。后续正式发布时新表会随既有 schema 初始化创建。
