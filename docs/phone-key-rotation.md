# 手机登录密钥兼容与轮换

2026-09-18 发布核查：生产已配置管理员令牌，但没有独立 PHONE_KEY / PHONE_SALT。现有 phoneHash 和账号加密依赖该令牌。此次发布保留原有效密钥，启动拒绝缺失/短密钥/公开默认值，并记录兼容模式，绝不在启动时随机生成替代密钥。没有输出或保存密钥值。

独立密钥轮换尚未实施。直接更换 PHONE_KEY 会使旧加密账号无法解密；直接更换 PHONE_SALT 会使历史手机号索引无法匹配。

后续迁移必须：
1. 验证可恢复备份，固定并安全保管现有有效密钥；先准备支持旧/新密钥版本的解密读取。
2. 账号密文添加密钥版本，先双读旧新格式，再以新独立密钥写新记录，逐批重加密并核对解密结果；之后才能停止旧密钥读取。
3. 盐不可只靠旧哈希转换。需要认证时获得原手机号后更新，或维护旧/新索引双查与唯一约束；过渡期同一手机号不能绑定两账号。
4. 在隔离副本验证登录、验证码、绑定、找回、并发唯一性和回滚。生产轮换单独执行，不能与盲目更新管理员令牌混在一起。

此发布修复启动校验和阻止静默默认密钥，并未声称完成独立密钥轮换。
