## 生日（每人每赛季一次，窗口 7 天）

| 选择 | 成本 | 付款方 | 行动力 | 效果 |
|---|---|---|---|---|
| 当天 | — | — | — | 士气 +1（不管经理做不做） |
| 送祝福 | 免费 | — | 0 | 士气 +2，信任 +1 |
| 送小礼物 | $200 | 经理个人钱包 | 0 | 士气 +5，信任 +3 |
| 组织简短庆祝 | $2,500 | 俱乐部财务（记账） | 1（venture） | 他士气 +6、信任 +3；全队士气 +2；他和每个人关系 +2 |
| 暂不处理 | — | — | 0 | 无 |

原来的自动 +3 士气拆成「当天 +1」和「送祝福 +2」，不叠加。信任的范围是 0–100，一次 +3 相当于一周正常带队的增量；关系 +2 是一次双排的一半。

## 更衣室争执（窗口 14 天，付费尝试最多 2 次，间隔 7 天）

| 选择 | 行动力 | 成功率 | 成功 | 失败 |
|---|---|---|---|---|
| 私下谈话（选一人） | 1 | 0.5 + (更衣室−50)×0.006 + (对方信任−62)×0.004 ± 经理状态，夹在 0.2–0.9 | 关系 +6～10，他信任 +2.5，士气 +3，关闭 | 关系 +1，他信任 −2，士气 −1，保持开放 |
| 组织调解 | 1 | 0.35 + (更衣室−50)×0.008 + (关系+50)/250 ± 经理状态，夹在 0.15–0.85 | 关系 +14～20，两人信任 +1.5、士气 +3、不满 −3，关闭 | 关系 −3，两人士气 −2，保持开放 |
| 安排双排 | 0 | — | 写入本周双排练（随团队训练结算，关系 +3～6） | — |
| 暂时替补（选一人） | 0 | — | 7 天不进首发；他信任 −3、士气 −4、不满 +3；两人关系 +3 | 替补不足五人则拒绝 |
| 暂不介入 | 0 | — | 标记忽略 | — |
| 两周没人管 | — | — | 双方士气 −2、不满 +2，一次 | — |

随机数种子是 `存档种子 + 记录 id + 选择 + 第几次`，读档不会换结果。原有的每周 18% 「还没和好」扣分照旧，是持续状态。

## 经理生活

| 项 | 值 |
|---|---|
| 年龄 | 开档年龄 +（当前赛季 − 开档赛季）；旧存档从迁移赛季起算 |
| 工资 | 合同年薪 ÷ 12，按游戏日历的月发放，每月一次；下课后停发；年末不再另记一年 |
| 旧存档结转 | 之前已结算的 `tally.earned` 一次性转入钱包，当月不补发 |
| 饱腹 | 起始 85，每游戏日 −4；低于 30 算饥饿 |
| 心情 | 起始 70，每游戏日 −1 直到 40 为止（吃饱的经理不管它也不会见底），饥饿时再 −2 |
| 便饭 | $30，饱腹 +35，心情 +1，无冷却 |
| 好好吃一顿 | $120，饱腹 +60，心情 +6，每天一次 |
| 休息一下 | 免费，心情 +8，每天一次 |
| 娱乐活动 | $300，心情 +20，三天一次 |
| 自动补给 | 饱腹 < 55 时买设定的餐食，受每月预算和余额限制，停下时提醒 |
| 状态修正 | 1 + clamp((饱腹−60)/100×0.06 + (心情−60)/100×0.08, −0.08, +0.08)，只作用于本队训练收益和谈话/调解成功率 |

最低档年薪（$60K × 0.75）折合月薪约 $3,800，每天一顿便饭一个月约 $100，所以基础饮食随便负担；娱乐 $300 三天一次是可选开销，月薪高的人不在乎、低的人要想一想。

## 版本公告

- 版本以国际赛结算为界（第一站大师赛、第二站大师赛、冠军赛），冠军赛后是大改；地区赛不换。
- 记录带 `id = 年-赛段-天`、年份、影响阶段（第二赛段起 / 冠军赛起 / 下赛季起），保留最近 8 个。
- 本队建议按三个数分列：版本（预案五人系数平均，`versionN`）、地图适配（`alignN`）、熟练度（`familiarity`）。预案里被削的英雄，若同位置有系数高 0.4 以上的英雄且他练到 60% 以上，建议换；否则建议去练；再否则说明差得不多。

## 训练推荐

- 唯一上限 `ATTR_MAX = 99`，推荐、每周结算、冬季成长共用。AI 俱乐部的同一套判断在 `AI_POLISH_STOP = 97` 停手：不是上限，是十个赛季 AI 强度曲线（`check_ai_growth`，前十名峰值 < 94）调校时的那条线，去掉它峰值会到 94.4。
- 顺序：受伤 → 疲劳 ≥ 45 → 总评到潜力 → 按位置权重挑第一个还能涨的属性；每一步都给一句理由。
- 手动选了已满的属性：不攒进度，页面提示；推进不会覆盖手动选择。

## 荣誉

- 冠军记录 `{年, 赛事, key, 赛段, 俱乐部 id, 俱乐部名, 天, 首发/替补席, 国际赛}`，整个 roster 都记，同一赛事同年只记一次，上限 200。
- 入队/离队/解约/合同到期/退役都更新效力经历。
